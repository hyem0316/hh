      메모 남기기

      설정

      1. Firebase 실시간 연결

      비어 있으면 이 브라우저에만 저장되는 로컬 체험 모드로 동작해요. Firebase 설정을 넣으면 다섯 명이 같은 방·같은 작업실을 실시간으로 함께 봐요.

      초대 링크를 다른 네 명에게 보내면, 링크만 열어도 같은 Firebase에 자동 연결돼요. (링크에 Firebase 설정이 담겨 있어요)

      Firebase 5단계 설정 가이드 (처음이면 여기부터)
      1. 프로젝트 만들기 — console.firebase.google.com 접속 → 프로젝트 추가 → 이름은 아무거나(예: pickle-office) → Google 애널리틱스는 꺼도 됩니다.
      2. Realtime Database 켜기 — 왼쪽 메뉴 빌드 > Realtime Database → 데이터베이스 만들기 → 위치 선택(가까운 곳: asia-southeast1) → 테스트 모드로 시작.
      3. 웹 앱 등록 — 왼쪽 위 톱니바퀴 프로젝트 설정 → 아래 내 앱 → </> 웹 아이콘 → 앱 닉네임 입력 → 앱 등록.
      4. 설정 복사 — 화면에 나오는 const firebaseConfig = { ... }; 를 통째로 복사해 위 칸에 붙여넣으세요. databaseURL 이 없으면 Realtime Database 화면 맨 위의 https://...firebasedatabase.app 주소를 직접 넣으면 됩니다.
      5. 저장하고 연결 — 저장하고 연결 을 누르고 위 상태가 실시간 연결됨 으로 바뀌면 성공. 링크 복사 로 나머지 네 명에게 초대 링크를 보내세요. (무료 Spark 요금제로 충분해요)

      2. 입장 비밀번호

      비밀번호는 이 기기에만 저장돼요. 다른 기기는 각자 설정하고, 기본값은 0316 입니다.

      3. 데이터·기기 관리

      로컬 초기화는 이 브라우저에 저장된 체험용 채팅·작업·메모·일정·사용량을 지웁니다. Firebase에 저장된 내용은 지워지지 않아요.

      📱 홈화면에 앱으로 추가하는 법

      갤럭시(안드로이드)에서는 이 페이지를 앱처럼 홈화면에 놓을 수 있어요. 주소창 없이 열리고, 아이콘도 생겨요.

      1

      크롬(Chrome)에서 — 오른쪽 위 ⋮ → 앱 설치(또는 홈 화면에 추가) → 설치.

      2

      삼성 인터넷에서 — 오른쪽 아래 ≡ → 현재 페이지 추가 → 홈 화면.

      3

      파이어폭스·웨일 등 — 메뉴의 홈 화면에 추가를 누르면 돼요.

      한 번 추가하면 앱 서랍이나 홈화면의 합동 비서실 아이콘으로 바로 열려요. 비밀번호(0316)와 저장 내용은 그대로예요. 설치 버튼이 안 보이면 위 메뉴 방법을 쓰시면 됩니다.
