## 두 가지 동작 모드

1. **로컬 체험 모드** (기본) — Firebase 설정이 없을 때. 이 브라우저의 `localStorage`에만 저장되고,
   샘플 대화·작업·메모가 들어 있습니다. 다른 기기와 공유되지 않습니다.
   상단 배지가 `● 로컬 체험 모드` 로 표시되고, 누르면 설정이 열립니다.
2. **실시간 모드** — Firebase Realtime Database를 연결하면 다섯 명이 같은 방·작업실·메모를 실시간으로 봅니다.
   상단 배지가 `● 실시간 연결` 로 바뀝니다.

## Firebase 연결 (5단계)

1. <https://console.firebase.google.com> → **프로젝트 추가** (이름 예: `pickle-office`, 애널리틱스는 꺼도 됨)
2. 왼쪽 **빌드 > Realtime Database** → **데이터베이스 만들기** → 위치(예: `asia-southeast1`) → **테스트 모드로 시작**
3. 왼쪽 위 톱니바퀴 **프로젝트 설정** → **내 앱** → `</>` 웹 아이콘 → 앱 닉네임 입력 → **앱 등록**
4. 나오는 `const firebaseConfig = { ... };` 를 통째로 복사 → 앱의 **⚙️ 설정** 칸에 붙여넣기
   (`databaseURL` 이 없으면 Realtime Database 화면 맨 위의 `https://...firebasedatabase.app` 주소를 직접 넣으면 됩니다)
5. **저장하고 연결** → 배지가 `● 실시간 연결` 이 되면 성공. **링크 복사** 로 만든 초대 링크를 나머지 네 명에게 보내면,
   링크만 열어도 같은 Firebase에 자동 연결됩니다. (주소 뒤 `#cfg=...` 부분에 설정이 담겨 있습니다)

무료 **Spark 요금제**로 이 정도 사용은 충분합니다.

### 데이터 구조

```
pickle-office/v1
├── chat/{messageId}    { room, sender, text, ts }
├── meta/pins/{room}    messageId  (방별 공지 하나)
├── todos/{todoId}      { title, category, assignee, status, by, ts }
├── memos/{memoId}      { title, body, pinned, by, ts, updated }
└── profiles/{memberId} { room, status, updated }
```

`room` 은 `meeting` · `command` · `lounge`, `status`(비서)는 `waiting` · `working` · `resting`,
`status`(작업)는 `waiting` · `doing` · `done` 입니다.

## ⚠️ 보안에 대해 (꼭 읽어 주세요)

- GitHub Pages는 **주소만 알면 누구나 열 수 있는 공개 정적 호스팅**입니다. 비밀번호 화면은 잠깐 막아 주는
  잔금장치이고, 소스 코드도 누구나 볼 수 있습니다. **민감한 개인정보는 올리지 마세요.**
- 실제 보호는 **Firebase 보안 규칙**으로 합니다. 콘솔에서 만든 직후의 "테스트 모드" 규칙은
  **30일 뒤 자동으로 막히고**, 그 전까지는 주소를 아는 사람이 읽을 수 있습니다.
- 로그인 기능을 붙이지 않은 이 앱은 **규칙이 열려 있어야 동작**합니다. 아래 규칙은 테스트 모드와 같은
  "공개 읽기/쓰기"지만 30일 뒤에 막히지 않습니다. 비서실 다섯 명만 쓰는 작은 공간이라면 이 정도로 두고,
  **정말 감춰야 하는 내용은 올리지 않는 것**이 가장 확실합니다.

```json
{
  "rules": {
    "pickle-office": {
      ".read": false,
      ".write": false,
      "v1": {
        ".read": true,
        ".write": true
      }
    }
  }
}
```

- 더 강한 보호가 필요하면 Firebase **Authentication**(익명 로그인 또는 Google 로그인)을 켜고
  규칙을 `"auth != null"` 로 바꾸는 방법이 있습니다. 이때는 앱에서 로그인 처리를 따로 해야 합니다.

## 문제가 생기면

- **배지가 "연결 오류"** — 설정에서 `databaseURL` 과 Realtime Database 규칙을 확인하세요.
- **다른 기기와 내용이 달라요** — 그 기기가 로컬 체험 모드일 수 있습니다. 설정에서 같은 초대 링크를 열어 주세요.
- **비밀번호를 잊었어요** — 비밀번호는 기기에만 저장됩니다. 새 기기라면 기본값 `0316` 으로 들어간 뒤 바꾸세요.
- **데이터를 처음 상태로** — 설정 → 로컬 데이터 초기화 (Firebase 내용은 그대로 남습니다).
